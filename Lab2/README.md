# Laboratorio 2: Configuración Vlan 

## Objetivo:
Configurar Vlan para mejorar el trafico y el rendimiento en una red

## Topología y Equipos:
- Dispositivo: Cisco 7200 Router (IOS 15.2)
- Herramienta de simulación: GNS3
- 2 X Cisco IOU L2 Switch (IOS 15.1) 
- Equipos de prueba: 12 x VPCS
  


## Configuraciones:
 - Creacion de Vlan
 - Asignacion de puertos en modo Access y Trunk 
 - Segmentacion de la red en capa 3 y 2
 - Uso de Router on a Stick como forma de Ruteo enntre Vlans
